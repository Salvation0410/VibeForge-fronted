# 客服知识档案工作台

用户已确认采用浅色、青蓝重点色、独立上传面板与紧凑文档表方向。

## 设计

页面沿用后台外壳，以暖白底色、深墨文字、青蓝强调和细分隔线呈现档案管理工作台。标题区使用小号英文栏目标签、大号中文标题和简短用途说明；总文档数来自服务端分页总数，不虚构统计。服务状态采用紧凑状态条，检查中、正常、不可用明确区分。上传区独立成左右布局，清楚标注格式、大小、所选文件及提交状态。

文档表将名称、格式与大小合并展示；索引状态与失败原因同列，分片数量和版本组合展示，减少水平滚动。操作保留处理记录、重试、启用/停用与确认删除，全量重建下沉到文档区次级操作。处理记录抽屉保留时间线、进度、重试和调度信息，并强化阅读层级。窄屏下上传区与标题纵向排列，表格仅在容器内滚动。支持键盘焦点与减少动效偏好。
